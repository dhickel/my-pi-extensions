# Subagents (Superseded)

This original design sketch has been superseded. The implemented contract is a **flat, root-owned pool** with exact tool policies — nested subagents are **unsupported**.

See [`subagents/README.md`](subagents/README.md) for the current public contract including exact tool-name arrays and fingerprints, atomic spawn-batch rejection, immutable result snapshots, UTF-8-safe pagination, and bounded terminal cancellation and detachment.
