## Key Takeaways

- Run Python validation with `PYTHONDONTWRITEBYTECODE=1`; Python caches are not ignored in this repository. A default interpreter run creates untracked `__pycache__` files; never include them in a snapshot commit. Passing the 102 computational tests does not establish Phase02 native visual/publication acceptance, and an explicitly authorized WIP merge does not change that status.
- The implementation repository is the plural `~/AI/Workspaces/Pi-extensions`, not the source-assets consumer. Consumer roots must be explicit; package locations resolve code/resources only.
- Generic internal-dev `plan` artifacts require seven canonical H2 headings. Generated Sprint Planner orchestration requires six different exact H2 headings. Do not publish orchestration as a generic phase artifact or alter unrelated contracts to force it. Raw accepted prose can use ordinary phase plans and independent evidence reviews. A temporary structural inspector PASS is not live advanced-plan acceptance, configured provenance, or a frozen execution record.
- The installed plan-validation result version is 1; execution-record version is 2. An earlier planning assumption conflated those versions. Inspect authoritative constants rather than attributing the assumption to the user.
- A target-bound, model-free SDK helper can invoke the actual registered internal_dev wrapper with genuine runtime context, actual schema validation, and Pi's own project-trust resolver. The helper must reject interception handlers because direct wrapped execution omits tool_call/tool_result and transcript events. This narrowly verified bootstrap is not a general permission pipeline.
- Trust currently resolves through Pi's no-protected-project-resources branch, not a saved user grant. Begin untrusted and use the resolver's real decision; never fabricate context or set trust automatically. A later protected-resource requirement must stop for real approval. Empty in-memory credentials, no models file, disabled refresh/warming, no prompt, and zero network tripwires established no model work for this bootstrap.
- Await exactly one actual session_shutdown emission before SDK disposal. Raw disposal is not equivalent to arbitrary extension shutdown hooks. This task does not repair upstream issue #2 or claim an orphan process was demonstrated.
- Normal phase workers use user-directed inheritance, not the configured Sprint Planner routes. Preflight reported `openai-codex/gpt-6.1-sol:max`; independent repair/PASS still gates dependencies. Pre-implementation senior advisories used the same provider/model at high under the loaded escalation contract; they are not package implementation/visual approvals.
- Preserve the eleven pre-existing modified/untracked files. The task's accepted decision is an appended owned hunk in an already dirty file: stage only that hunk, never the unrelated model edits or a blanket worktree.
- RPGW-specific transparent sprite gutters and closed transparent-decoration alpha crops are not universal completeness rules. Complete opaque/border-touching frames and bounded manual atlas stamps are valid. Preserve explicit full grid/rectangle geometry, original pixels, nonempty art and visibility; independent review establishes semantic completeness rather than an alpha classifier. Seven focused tests plus the original suite prove the repaired numeric/pixel boundary.
- Reject nonfinite JSON numbers through parse_float as well as parse_constant: an overflow literal such as 1e999 does not use the latter. Also reject booleans as integer geometry and close Pillow image handles when reading dimensions.
- Inspect actual report/baseline schemas before assertions: build's test_only flag is nested in source_approval, and protected-source baseline values are {bytes,sha256} under consumer-root-relative keys. A successful exclusive candidate creation must be read back after a verification-harness failure, not retried.
- Actual internal_dev changelog creation requires an empty supplied Git Commit section; the tool injects current HEAD. A prefilled hash is rejected before writing. Root verified the actual normalization path with the Phase01 changelog.
- Source review may use actual opened contact pages only when complete member paths/hashes/display rectangles are retained. The 48 opened images here cover all 56 roles via four-way original/candidate/frozen/copied-frozen rows plus source/frame/parts/gallery contexts. JSON totals or automated composition alone do not establish viewing.
- Count aliases separately from animations. Each current fixture has two animations but one alias; tests must address an actual declared identity rather than infer alias count.
- The preflight Python 3.12 assumption was stale: actual installed runtime is Python 3.14.7 with Pillow 12.3.0 and NumPy 2.5.1. The accepted contract uses the available interpreter/dependency minima. AST grammar parsing for 3.12 proves syntax only, never execution or a need to install that minor version.
- Mathematical corner coverage and native/generated pixel agreement can share a wrong source recipe. Independent full-source role review and actual native every-stroke semantic image review remain distinct gates. Missing or stale review must block exact-bundle publication; JSON hashes do not prove image viewing.
- Finite Wang solving and raw finite tile-layer storage are different APIs. Actual Tiled 1.12.2 clips Wang solve rectangles, while `TileLayer.edit().setTile(-1,-1,realTile).apply()` can retain an outside cell. A null outside Wang request is not a positive raw-storage/pruning control. Bind the actual API, geometry, tile ID/flags and nominal dimensions separately.
- Native evaluate may exit zero after JS errors, even after an apparent success sentinel. Consume complete bounded stdout/stderr, reject errors anywhere and require one exact run-specific terminal whole-line token plus the complete expected readback inventory. Four real before/after/duplicate/missing controls exercised this boundary.
- A failing class setup can leave every intended readback method unexecuted. Test inspection IDs still obey lowercase production grammar; register exception-safe temporary/root cleanup before later setup checks and verify actual executed method counts.
- Revalidate complete seal identity/content and closed original membership, not merely existing declared file hashes. Newly undeclared originals and honest-hash metadata changes still alter the trust boundary. Parse, validate and hash the same reviewer snapshot; replacement during parsing must not approve unchecked bytes.
- Prepare old selector recovery bytes durably before replacement. Include full-report serialization/write/hash, bounded validation/output delivery, input recheck and child settlement inside exception rollback. Hold the canonical-root lock through descendant settlement, not only direct Popen exit. This is controlled single-selector recovery, not general crash/multifile atomicity.
- Complete native review bindings can exceed128MiB with ordinary specific observations. The real2931-item/174605-view binding and explicitly synthetic100-character capacity notes measured135237321bytes, UNAPPROVED/BLOCKED. Private complete-evidence bounds and256KiB public responses are different contracts; do not reduce coverage or invent terse findings to fit.
- Any shipped-code change, including a private evidence-size limit, changes the complete tool identity. Genuine source-v5 approval became stale after that limit repair; source-v6 was actually viewed anew. Never patch hashes in an old approval to make it current.
- Inspect manifest/report schemas before writing scratch harnesses: the original inventory key is `inventory`, and bounded failure uses singular `error`, not `errors`. Failed guessed-key attempts are preserved, not relabeled as product failures.
- An outer harness timeout does not settle a CLI's private PGID. Verify the exact argv, canonical root, owner record and process group; signal only invocation-owned work and await settlement. Native evidence preparation may precede the native ownership marker, so an overly short observation deadline is not proof that native execution is unavailable.
- Binding arrays must use explicit canonical channel order, not dictionary `.values()` insertion order. Sorted JSON serialization changed stdout/stderr order and caused all2931 bindings per consumer to fail complete validation before the reviewer parser. Round-trip the complete production representation, not only a constructed unit object.
- A BLOCKED return does not prove the requested negative gate was reached. Record the exact failure boundary and injection-hit/lifecycle position; both production guards failed on binding coverage, so prior missing-review assertions were overstated. Passing82 tests and retained5712-stage pixel reconstruction did not establish safe publication.
- Signal boundaries include the interval after actual selector rename but before the commit flag, and the terminal report settlement path. Exact content must be rechecked even when the staging inode is unchanged. Rollback must preserve a foreign replacement inode even when its bytes happen to equal intended content. Fsync recovery directory entries before replacement, not only recovery file bytes.
- Direct process disappearance is not group settlement. A TERM-resistant owned descendant acquired the consumer lock during interrupted terminal settlement; lock acquisition by an adversarial owned descendant is a decisive lifecycle control. Keep the lock through bounded TERM/KILL/drain/reap despite cancellation.
- Closed untrusted schemas require object checks before `.get()` and strict integer type checks before comparisons. Candidate JSON `[]` escaped bounded failure output, and booleans passed nested numeric readback equality (`True == 1`). Schema failures are not eight successful controls or internal tracebacks.
- Case names and mask/render equality do not prove topology or crop completeness. Check named boundary/axis against actual motion, width-two tip support against the crop rectangle, and independently assert nested-gap/bridge connectivity and separation with honest negative fields. No blanket contact crop substitutes for the required local view.
- Prepared compositional pages and complete hashes are not semantic viewing. Audit63 prepared2926 member sheets but opened none of them; only two isolated native point pages and12 source pages were actually viewed. Record actual viewer identity and complete displayed membership, never infer approval from preparation/equality/counts.
- Exact native Qt premultiplied-buffer agreement is not necessarily identical nonzero-alpha straight RGB bytes because uint8 premultiplication is many-to-one. Senior67 verified original authoritative validators already use exact native premultiplied buffers; the living specification now names that inherited contract explicitly. Strict original/frozen decoded straight RGBA remains separate, with alpha-zero-only hidden RGB canonicalization and no tolerance/pixel changes.
- Final freshness belongs after actual complete review parsing: recheck the whole seal/candidate, source/protected membership, runtime content and exact review snapshot immediately before receipt creation. A real disposable launcher content mutation proves runtime freshness; a replaced hash getter does not.
- Rename bookkeeping and terminal delivery have separate signal boundaries. Block INT/TERM across real replacement/ownership verification/commit-state assignment. Complete fallible report/input/settlement work before write+flush; do not reopen an already delivered success through redundant late checks or restoring default signal handling during close.
- Tip support must use full end faces of overlapping width-two blocks and current stage/orientation. Nested/bridge topology asserts both A and B components reconstructed from actual native Wang vertices; an extra A bridge enclosing a B hole is a meaningful negative even if requested bank connectivity passes.
